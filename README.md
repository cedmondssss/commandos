# CommandOS

**Turn a spoken instruction into action on your Mac.**

CommandOS is a voice-controlled AI agent for macOS. Describe a task in everyday language, and it carries out supported workflows across your applications, files, and browser. You can also type commands.

## What it can do

- Take a photo in Photo Booth and prepare an email with the image attached.
- Organize screenshots and files into folders.
- Read documents and prepare summaries or reports.
- Operate Chrome to complete workflows such as creating and deleting a GitHub repository.
- Combine several actions into one request.

For example:

> “Take a picture of me and email it to myself.”

> “Move my five latest screenshots into a folder called HackBU Picks.”

> “Create a GitHub repository called HackBU, then delete that same empty demo repository.”

## Fast, visible, and under your control

**Fast execution:** Supported everyday commands can follow a direct workflow. More complex requests are broken into a plan.

**Visible actions:** Follow the plan, tool activity, and results as the agent works.

**Approval for consequential actions:** Review actions such as sending an email or deleting a repository before they proceed.

**Verified results:** CommandOS checks the resulting application state before reporting completion. When it cannot confirm an outcome, it reports the uncertainty.

**User controls:** Cancel a run, use emergency stop, or undo supported local changes.

## How it works

1. Speak or type a request.
2. CommandOS selects a supported workflow or builds a plan.
3. Native macOS tools carry out the actions, with permission checks along the way.
4. Results are checked and shown in the activity history.
